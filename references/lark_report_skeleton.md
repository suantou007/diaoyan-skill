# 飞书报告骨架模板

下面是推荐的飞书正文顺序。不是逐字模板，而是告诉你**每一类内容应该放在哪里**。

## 推荐顺序

1. **顶部执行摘要 Callout**  
   一句话介绍 + 核心亮点 + 关键差异 / 不足

2. **公司与团队 / 产品快照**  
   成立时间、融资、团队、用户、定位、场景、当前阶段

3. **核心功能拆解**  
   每个功能都按：**标题 → 图片 / grid → 时间戳 → 视频观察 → 网页确认 → 推断 / 开放问题 → 竞争意义**

4. **核心工作流 / 用户路径**  
   这里优先放飞书画板 / 工作流图，再写解释

5. **纵向演进**（完整竞品分析时）  
   先放时间线图，再展开关键节点

6. **横向对比**（完整竞品分析时）  
   先放竞品关系图 / 能力地图，再接对比表

7. **定价 / 套餐 / 评价**  
   结构化信息优先用表格；外部原话用引用块

8. **开放问题 / 未确认项 / 相关链接**

## 最简示例

```markdown
<callout emoji="📌" background-color="light-orange">
**一句话介绍**：...

**核心亮点**
1. ...
2. ...

**关键差异 / 不足**
1. ...
</callout>

## 1. 功能标题
[这里放图片 / grid]

时间戳：00:01:24 - 00:01:42

**视频观察**
...

**网页确认**
...

**推断 / 开放问题**
...

**竞争意义**
...

## 核心工作流 / 用户路径
[这里放飞书画板 / 流程图]
```

## 核心原则

- 标题之后先放图，再写解释
- 重要判断前置，不要埋到文档后半段
- 图示和表格都要出现在所属章节内部
- 不要把所有截图、所有图、所有表堆到文档末尾
