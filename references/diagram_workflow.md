# 图示与截图交付规则

图示是正文的一部分，不是装饰。默认优先飞书画板，HTML 使用 SVG、PNG 或截图 grid。

## 必须规划的三类视觉材料

### 产品全貌图

位置：产品简介之后。

- 并排放 2 至 4 张官网首页、编辑器首页、社区或内容首页、关键终端首页
- 优先让读者一眼看出产品是什么、由哪些部分构成
- 编辑器不可公开访问时，依次回退到录屏中的编辑器总览、官方帮助中心素材
- 使用截图 grid，不需要画板

### 体验流程图

位置：体验流程分析开头。

- 表达入口 → 输入 → 生成或处理 → 编辑与反馈 → 导出或分享
- 简单标准流程可用 Mermaid 画板
- 多角色、多分支或复杂反馈路径优先 SVG 画板
- 图后解释关键摩擦点和反馈机制

### 竞品关系图

位置：竞品分析开头或竞品总表之前。

- 表达 3 至 4 个候选竞品与本产品之间的选择逻辑
- 可以使用二维定位图、关系图或能力地图
- 复杂布局优先 SVG 画板

## 默认链路

1. 确定图表意图和所属章节
2. 本地生成 SVG 或 Mermaid
3. 写入飞书画板
4. 预览确认布局
5. 在对应章节放解释文字和竞争判断

不要把所有图集中堆到文档末尾。

## 并排截图规则

以下关系默认使用 grid / 分栏同排展示：

- 官网首页与编辑器首页
- 入口与结果
- 输入与反馈
- 前与后
- 多个候选结果
- 多个竞品界面

每张截图必须有短图注，说明读者应看见的产品角色或功能状态。
