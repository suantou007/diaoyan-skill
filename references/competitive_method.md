# 竞品分析方法：横纵分析法（HV）

当任务是**竞品分析 / 敏捷研究 / 深度研究**时，默认采用横纵分析法组织内容，而不是只列功能点。

这个方法来自 `hv-analysis` skill，可压缩成适合本 skill 的轻量版本：

## 1. 纵轴：讲清楚它是怎么走到今天的

纵轴关注研究对象从诞生到现在的演进过程。至少回答：

- 它最初是为什么出现的？
- 早期定位和今天有什么变化？
- 关键版本、关键产品决策、关键定价变化是什么？
- 哪些历史决策塑造了它今天的优势？
- 哪些历史包袱塑造了它今天的短板？

适合放进纵轴的信息：

- 产品起源
- 创始团队或核心背景
- 关键版本迭代
- 重要战略转向
- 商业化 / 定价变化
- 用户增长或市场节点

## 2. 横轴：把它放回当前竞争格局里

横轴是在**当前时间点**，把它与主要竞品进行系统对比。至少覆盖：

- 目标用户
- 核心场景
- 工作流完整度
- 质量 / 稳定性 / 可控性
- 协作与交付能力
- 定价 / 套餐 / 限额
- 企业化能力 / 集成能力

不要只写“谁有这个功能、谁没有”。要回答：

- 用户为什么会选它？
- 它在赛道里占的是什么位置？
- 它的真正替代品是谁？

## 3. 横纵交汇：给出判断

最有价值的部分，不是再重复一遍事实，而是回答：

- 历史是如何塑造今天的竞争位置的？
- 今天的优势能追溯到哪些历史决策？
- 今天的弱点是不是过去的好决策留下的副作用？
- 如果往后推演，它最可能、最危险、最乐观的剧本分别是什么？

## 4. 在本 skill 里的落地方式

如果用户只是要“这个视频里做了什么”，按证据型视频调研流程输出即可。

如果用户要的是“竞品分析 / 敏捷研究 / 帮我判断这个东西怎么样”，则应把结果组织成：

1. 执行摘要
2. 产品快照
3. 证据型功能拆解
4. 纵向演进
5. 横向对比
6. 横纵交汇洞察
7. 风险 / 机会 / 未确认问题

## 5. 与视频录屏调研的关系

视频录屏解决的是“你看到了什么”。
横纵分析法解决的是“这些事实意味着什么”。

前者是证据层，后者是判断层。不要跳过证据直接下判断，也不要停在证据层不做判断。
