# 产品调研报告结构 4.0

只要本 skill 产出飞书文档或 `notes.html`，就必须使用这份结构。当前默认飞书模板：

- Wiki：https://my.feishu.cn/wiki/CodewL09NilctEkYl65cB2dVndc
- Docx：https://bytedance.larkoffice.com/docx/WvkSdNbOIoWMQWxz4qKczdH0nge

## 生成顺序

先完成第 2 至第 6 章，最后根据全文反向提炼第 1 章“速览结论”。展示时仍将速览放在文章开头。

## 1. 速览结论

速览是结构化阅读入口，不是中性摘要。建议使用 callout + 分组列表，覆盖：

- **总体判断**：一句话说明产品是什么、服务谁、当前竞争位置
- **产品构成**：列出主要产品、社区、创作工具或终端形态
- **关键模块**：列出最值得理解的 2 至 4 个模块
- **亮点**：2 至 3 条
- **短板**：2 至 3 条
- **综合竞争判断**：一句话说明潜力、关键前提或核心约束

每条内容必须能回指正文，不写正文未支持的新判断。

## 2. 基本信息与关键数据

用表格呈现：

| 项目 | 内容 |
|-|-|
| 产品名 |  |
| 所属公司 / 团队 |  |
| 上线时间 | YYYY.MM |
| 平台 | iOS / Android / Web / 小程序等 |
| 产品定位 | 一句话定位 |
| 目标用户 | 一句话用户画像 |
| 融资 / 投资 | 金额、轮次、时间、投资方 |
| 用户规模 | DAU / MAU / 下载量 / 注册用户 / 客户数量 |
| 定价计划 | 公开档位、价格、周期、额度与限制 |
| 官网 / 下载 | 直接链接 |

规则：

- 关键数字必须带时间口径。
- 查不到则写“未公开 / 未找到 / 未核验”，不删除字段。
- 若数字或事实来自资料查询，在对应单元格内就近嵌入简短超链接，例如“完成 A 轮融资（[融资公告](URL)）”。
- 不生成统一来源尾注；没有使用外部资料的字段不附链接。

## 3. 产品简介

用自然段说明背景，必须使用以下加粗锚点：

- **产品定位**
- **核心需求**
- **主体验**
- **当前阶段**

简介之后立即加入“产品全貌”图片组：

- 默认 2 至 4 张并排截图
- 优先官网首页、编辑器首页、社区或内容首页、关键终端首页
- 编辑器不可公开访问时，依次回退到录屏中的编辑器总览、官方帮助中心素材
- 图注说明该界面体现的产品角色，不写取证过程

若简介中的背景或阶段判断来自资料查询，在对应句子后嵌入简短超链接。纯录屏观察不附来源，不生成统一来源尾注。

## 4. 体验流程分析

把产品作为完整体验来分析，同时把关键能力主题并入流程主线。默认梳理：

1. 入口与 onboarding
2. 输入或创建
3. 生成、处理或执行
4. 编辑、迭代与反馈
5. 导出、发布、分享或消费

交付要求：

- 至少提供一张流程图或一张流程表。
- 在主流程下归并 3 至 6 个关键能力主题。
- 每个主题使用“小标题 → 功能说明 → 匹配截图与短图注 → 体验判断”。
- 标出关键反馈、等待、跳转、付费点和摩擦点。
- 区分录屏直接观察与网页补充确认。
- 截图必须准确展示对应步骤或能力主题，不能用相邻但无关的画面。
- 图注只写界面角色、输入输出或体验含义，不写 `00:01:10` 这类显式时间。
- 录屏观察不附来源；若补充引用官方流程说明，在对应步骤或判断后嵌入简短超链接。

## 5. 竞品分析

竞品优先从用户提供的 Base / bitable / 表格竞品池中选择；仅当池内资料不足或没有合适对象时，再补外部搜索。

选择规则：

- 先从本产品体验流程中提炼 2 至 4 个最值得比较的维度。
- 默认选择 3 至 4 个最相关竞品，不强制拆成亮点组和同类型组。
- 优先直接竞争关系、资料完整度和与本产品的可比性。
- 候选不足时允许补 Tavily / WebSearch / `web.run`。

每个竞品至少覆盖：

| 产品 | 产品定位 | 用户画像 | 功能概述 | 差距 / 优势 | 可借鉴点 |
|-|-|-|-|-|-|

末尾写“竞争判断”，合并本产品亮点、短板、竞争位置和关键约束。不要另设机会风险或后续建议章节。

竞品事实若来自资料查询，在对应产品名、数据或表格单元格内嵌入简短超链接。不生成统一来源尾注。

## 6. 主要信息来源

分两组整理：

### 官方信息

- 官网、官方帮助中心、定价页、公告、博客、应用商店页、公司或创始人官方页面

### 非官方信息

- 媒体报道、投资机构页面、数据平台、用户社区、评论与第三方测评

只列页面标题，并把标题设置为可点击超链接：

```text
[页面标题](URL)
```

不列搜索关键词、工具名、搜索过程、失败记录或泛泛的“外部检索”说明。

## 缺失信息处理

- `未公开`：公开资料没有披露
- `未找到`：已搜索但没有可靠来源
- `未核验`：有线索但缺少可靠确认
- `视频未展示`：录屏没有直接证据
- `不适用`：该维度确实不适合产品

内部一致性检查、工具过程、重试日志和证据分层细节只写入 `analysis_manifest.json`。
